# qichi · Figma 练习清单(页面 + 元素)

> 目的:用 qichi 这个真实产品练 Figma 低保真原型,练完直接当作品集。
> 原则:**只画低保真**(灰块 + 文字占位,不上色、不抠细节),重点是**结构 + 流程**。
> 机型:Figma 新建 Frame 选 **iPhone 16 / 16 Pro**(390×844 左右)即可,全程用竖屏。

---

## 0. 练习前的准备(10 分钟)

- [ ] 新建一个 Figma 文件,命名 `qichi 低保真原型`
- [ ] 从 Figma 社区导入一套免费 **UI Kit**(搜 "iOS UI Kit" 或 "Wireframe Kit"),后面直接拖现成按钮/输入框,别自己画
- [ ] 装插件:`Iconify`(图标)、`Unsplash`(占位图)
- [ ] 约定一套占位规则:文字用真实中文短句,图片/头像用灰色方块/圆,图标用线框图标

---

## 1. 欢迎页 Welcome

**布局:整屏居中,从上到下垂直排列**

- [ ] App Logo / 名称（顶部，文字占位 `qichi`）
- [ ] 主插画区（一个大灰色方块占位，代表宠物/品牌图）
- [ ] 标题文案（如 "求职路上，有人陪你"）
- [ ] 副标题 / 一句话介绍（小字）
- [ ] 主按钮「开始」（实心大按钮）

🎯 练习点：垂直 Auto Layout、按钮组件、文字层级（标题/副标题大小区分）

## 2. 选宠物页 Pet Select

**布局:顶部标题 + 中间宠物横向排列 + 底部确认按钮**

- [ ] 顶部标题（"选择你的陪伴宠物"）
- [ ] 宠物选项 × 3~4（每个 = 圆形/方形灰块 + 名字，横向排列）
- [ ] **选中态**：被选中的宠物加一个边框高亮（练"选中 vs 未选中"两种状态）
- [ ] 底部确认按钮「就是你了」

🎯 练习点：横向 Auto Layout、选中态对比、间距均匀分布

---

## 3. 聊天页 Chat（核心主页）⭐

**布局:顶部栏 + 宠物舞台 + 消息列表 + 输入栏 + 底部 TabBar**

- [ ] 顶部 AppBar（标题 / 宠物名字，右侧可放一个图标按钮）
- [ ] **宠物舞台 PetStage**（上方一块区域，放宠物灰块占位）
- [ ] **消息列表**（从上往下排）：
  - [ ] 宠物消息气泡（靠左，灰色气泡 + 文字）
  - [ ] 用户消息气泡（靠右，深色气泡 + 文字）
  - [ ] 至少各画 2~3 条，体现一问一答
- [ ] **底部输入栏**：输入框 + 发送按钮（可加一个"+"或表情图标）
- [ ] **底部 TabBar**（聊天高亮）

🎯 练习点：**这是最练 Auto Layout 的页面**——消息气泡用 Auto Layout 让气泡随文字长度自适应；左右对齐区分两种说话人

## 全局组件：底部 TabBar ⭐

做成一个独立 Component,放在 3/4/6/7 四个页面底部:

- [ ] 4 个 Tab：聊天 / 小本本 / 曲线 / 我
- [ ] 每个 Tab = 图标 + 文字（上下排列）
- [ ] **高亮态**：当前页对应的 Tab 用品牌色（其余灰色）——用 Variants 做"激活/未激活"两种状态

🎯 练习点：**Component + Variants**(进阶但很值),一次做好,四页复用

---

## 最后一步：用 Prototype 连成可点 Demo ⭐⭐

把页面用交互连起来,做出"能点着走一遍"的原型:

1. 欢迎页「开始」按钮 → 选宠物页
2. 选宠物页「确认」 → 聊天页
3. 底部 TabBar 的 4 个 Tab → 互相跳转(聊天 ↔ 小本本 ↔ 曲线 ↔ 我)
4. 小本本卡片 → 复盘详情页;详情页返回箭头 → 小本本(选画)

操作:`Prototype` 标签 → 选中按钮拖连接线到目标页 → 触发 `On Click` / 动作 `Navigate to` → 右上角 ▶️ Present 预览。
