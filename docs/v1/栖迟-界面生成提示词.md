## 0. 使用方式

### 0.1 工具推荐

| 工具 | 适用场景 | 注意 |
|------|----------|------|
| **Midjourney v6 / v7** | 出概念图、视觉风格定调 | 可附 `--ar 9:19 --style raw` |
| **ChatGPT Image / Sora Image** | 出可读细节高的界面图 | 长 prompt 表现好 |
| **Galileo AI / Uizard** | 直接出 UI 稿可导 Figma | 适合后续直接落地 |
| **v0 / Lovable / Bolt** | 出可运行代码（跳过设计图） | 用作 P0 阶段后期 |

### 0.2 通用建议

1. **每张图都用同一段「共享样式锚定」开头**（见下方第 1 节），保证 5 张图调性统一
2. **AI 图像工具不擅长大段中文 UI 文字**：建议设计图中文字用占位（"……"），后续用 Figma 替换真文字
3. **若出图太"AI 味"**：在末尾追加 `feels like a handcrafted Figma file, not AI generated`
4. **比例**：移动端 9:19（推荐）/ 9:16
5. **种子复用**：5 张图建议用同一种子或同一参考图，保证视觉一致

## 1. 共享样式锚定（每张图开头都用）

```
A high-fidelity mobile UI mockup for a healing-style web app called "栖迟" (a soft companion app for job interview emotional reflection).

Visual style:
- Japanese healing aesthetic (日系治愈风), warm orange and cream color palette
- Background: warm cream white (#FFF8EE)
- Primary color: warm orange (#F5A65B)
- Accent colors: cream orange (#FCD9A8), butter yellow (#FFEFC9), warm pink (#FFD6CC), misty blue (#C7D6E0)
- Text color: gentle brown (#5A3E2B)
- Rounded corners everywhere: cards 20-24px, buttons 24px (pill shape), bubbles 16px
- Soft warm shadows (never harsh black), warm orange tint with low opacity
- Typography (strict rules):
  · ALL body text, UI controls, supplementary content, captions: use a **rounded modern sans-serif Chinese typeface** (similar to **OPPO Sans** / HarmonyOS Sans / 阿里巴巴普惠体) — clean, friendly, soft round terminals, breathing line height
  · Emotional content (pet's translated speech, mood card sentences, monthly summaries): SAME rounded sans-serif but with **lighter weight + looser line height** (1.8) for breathing feel
  · NEVER use kaishu / 楷书 typefaces (霞鹜文楷, 华文楷体, 方正楷体) for any body text — they feel too formal and stiff
  · NEVER use large Song-style serifs (思源宋体, 方正清刻本悦宋) for headlines or body — they break the healing feel
  · ONLY exception: tiny 13px Shijing (诗经) citation on the welcome screen may use a serif Song typeface as a cultural anchor
  · The brand wordmark 「栖迟」 is a hand-painted ink illustration (NOT a typeface choice) — soft brush strokes, warm ochre tones
  · English text: rounded sans-serif like Comfortaa (display) or Quicksand (body)
- Hand-drawn outline icons with 1.5px stroke, rounded line caps, slight imperfection
- Generous whitespace, low information density, calm and breathable layout
- Decorative elements: small clouds, moons, paw prints, gentle dotted lines
- Mood: like a soft handwritten journal, not a corporate app
- A chubby cartoon orange cat character (橘猫 IP) appears as the user's companion pet, with round body, big eyes, soft outlines

Format: mobile screen 9:16 aspect ratio, iPhone-like frame optional, single screen mockup, no annotations.
```

## 7. 生成顺序与协同建议

### 7.1 推荐顺序

1. **先出聊天主页**（界面 2）—— 因为它定义了产品的"日常视觉"，其他页都向它对齐
2. 出**欢迎 + 选择页**（界面 1）—— 已有调性后再做引导页更容易统一
3. 出**小本本**（界面 3）—— 复用聊天页底部 Tab 和卡片视觉
4. 出**心境曲线**（界面 4）—— 图表是最特殊的组件
5. 出**设置页**（界面 5）—— 最朴素的页，最后出

### 7.2 跨图一致性检查清单

每张图生成后，对照以下检查：

- [ ] 底部 Tab Bar 在 4 张主页面里**完全一致**（颜色、图标、字号、激活样式）
- [ ] 顶部条高度统一 56px
- [ ] 主色 / 文字色严格按 token 使用，无色偏
- [ ] 圆角值统一（卡片 20、按钮 24 胶囊、气泡 16）
- [ ] 宠物角色形象与之前生成的 IP 图**完全一致**
- [ ] 所有文字使用同一字体族（中文圆体黑 + 英文 Quicksand）
- [ ] 阴影都是暖橙调，无纯黑

### 7.3 如果某张图风格漂移

把这张图作为参考图（`/style ref`）+ 重新跑该页 prompt，强制对齐已确认风格。
