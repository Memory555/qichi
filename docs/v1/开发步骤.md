## 阶段 0 · 项目初始化（开发前置，1 次性）

### 0.1 Next.js 项目初始化

- [ ] **在 qichi 父目录创建 Next.js 骨架**（注意：现有 qichi/ 已有部分文件）

```bash
cd "D:/Markdown/Vibe Coding"
# 因 qichi/ 已存在，先 init 到临时目录
npx create-next-app@latest qichi-init \
  --typescript --tailwind --app --src-dir --eslint \
  --import-alias "@/*"

# 复制 Next.js 必要文件到 qichi/（保留已有 src/ public/ 和文档）
cp qichi-init/next.config.* qichi/
cp qichi-init/tsconfig.json qichi/
cp qichi-init/next-env.d.ts qichi/
cp qichi-init/eslint.config.* qichi/  # 或 .eslintrc.json，看版本

# 删除临时目录
rm -rf qichi-init
```

- [ ] `cd qichi && npm install`
- [ ] 额外安装：

```bash
npm install dexie dexie-react-hooks openai framer-motion recharts clsx tailwind-merge date-fns zod
```

### 0.2 环境变量

- [ ] `cp .env.example .env.local`
- [ ] 申请 OpenAI API Key（https://platform.openai.com/api-keys）填入 `OPENAI_API_KEY`
- [ ] （可选）如需走代理，填 `OPENAI_BASE_URL`（如 OpenRouter、Azure、国内中转）
- [ ] 验证：`echo $OPENAI_API_KEY` 不为空

### 0.3 字体子集化（可选但强烈建议）

- [ ] 把所有 `栖迟-*.md` + `项目说明.md` 文件内容拼起来去重提取字符集 → `chars.txt`
- [ ] 用 https://chinese-font.com/tools/subset 上传 3 个 TTF + chars.txt
- [ ] 把生成的 WOFF2 替换 `public/font/` 下的同名文件（确认压到 ~300KB/字重）

### 0.4 首次跑通

- [ ] `npm run dev`
- [ ] 打开 http://localhost:3000 看见 Next.js 默认页
- [ ] 改 `src/app/page.tsx` 加一行 `<div className="bg-page text-ink p-4">栖迟 token 测试</div>`
- [ ] 刷新看到暖橙背景 + 温柔棕文字 = ✅ Token 生效

### 0.5 Git 初始化

- [ ] `git init && git add . && git commit -m "init: 栖迟 项目骨架就位"`
- [ ] 在 GitHub 建私有仓库 → `git remote add origin ...` → `git push`

## 通用提醒

### 🌱 Vibe Coding 节奏

- 每个任务做完 commit 一次（commit message 写清"什么 + 为什么"）
- 一天最多推进 3-5 个任务，避免堆积
- 卡住 30 分钟以上 → 换一个任务，先做能做的
- 每完成一个阶段（如阶段 A），自己跑一遍验收清单

### 🧪 调试 Prompt 的方式

- 在 `src/lib/prompts.ts` 改 system prompt
- 命令行直接跑 `npx tsx -e "import { translateMessage } from './src/lib/llm.ts'; ..."` 测试
- 不要在浏览器疯狂点翻译刷 OpenAI 费用

### 🐶 当你卡壳的时候

- 重新读对应阶段的 [栖迟-UI功能说明.md](栖迟-UI功能说明.md) 章节
- 拿对应 `design-refs/ui-mockups/*.png` 喂给 Cursor / v0 重新生成代码
- 跟未来的自己说："允许写得糙一点，能跑就行"
