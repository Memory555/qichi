## A4 · ⚠️ CORS 红字坑（Vercel 必填代理）

**症状**：朋友在 Vercel 域名下聊天，控制台报：

```
Access to fetch at 'https://api.openai.com/v1/chat/completions'
from origin 'https://qichi.vercel.app' has been blocked by CORS policy
```

**原因**：OpenAI 官方 API 不发 CORS 头，浏览器直连必拒。

**唯一解**：**Base URL 必须填一个会发 CORS 头的代理**。
推荐 https://api.chatanywhere.tech/v1（免费 30 天 key）。

> 本地开发跑 localhost 时也可能"恰好能通"，那是因为之前手填过 chatanywhere；Vercel 域名是独立的 IndexedDB，得**单独配一遍**。

# 三、路径 B：Android APK 打包

> ⚠️ 首次打包预留 **2-3 小时**（主要在装 Android Studio + 下载 SDK + 国内网络抗争），打通一次后续每次 5 分钟。

## B1 · 安装 Android Studio

### B1.1 下载 + 安装

1. https://developer.android.com/studio → Windows 64-bit（~1.2 GB）
2. 双击 .exe，一路 Next，**安装路径建议 D 盘**（如 `D:\Android Studio\`）
3. 首次启动 → Welcome → Standard 安装 → 进入 SDK 组件向导

### B1.2 SDK Components Setup 向导（最容易卡的一关）

#### ⚠️ 坑 1：SDK 路径不能在 Android Studio 安装目录里

❌ 错的：`D:\Android Studio\Android\Sdk`
→ 红字 `The Android SDK location is inside Studio's install location`，所有组件灰着不让选

✅ 对的：`D:\Android\Sdk`（跟 Android Studio 平级，独立目录）

**修法**：点路径栏 📁 图标手动选 `D:\Android\Sdk`（不存在就在文件管理器里先建好这个空目录）

#### ⚠️ 坑 2：所有组件显示 `(unavailable)`

**原因**：向导拉不到 Google 的 SDK 清单（国内 dl.google.com 被墙）

**做法**：**直接点 Next 跳过**（Next 是亮的，不强制必装）→ 一路 Finish 走完向导 → 进 Android Studio 主界面 → 在主界面里**配代理 + 用 SDK Manager 装**

---

### B1.3 进主界面后立刻配代理（关键）

**File → Settings → Appearance & Behavior → System Settings → HTTP Proxy**

选 **Manual proxy configuration**：

| 字段 | 值 |
|------|---|
| Host name | `127.0.0.1` |
| Port number | `7890`（Clash 默认；你改过端口填实际的） |

**Check connection** → 输 `https://dl.google.com` → 弹「Connection successful」就 OK。

> ⚠️ **Clash 必须开 TUN Mode**（Clash 主界面 → General → TUN Mode → 打开）。Java 应用很多不读 Windows 系统代理，TUN 才能强制全局拦截。

> ⚠️ **节点选香港 / 日本**，别选美国。SDK 包动辄 100+ MB，节点不稳就会 `Connection closed at byte XXXXX. Expected YYYYY bytes`。

---

### B1.4 用 SDK Manager 装最小组件集

**File → Settings → Languages & Frameworks → Android SDK**

#### SDK Platforms 标签

| 勾 | 项 | 大小 |
|----|----|------|
| ✅ | **Android 14 (API 34)** | ~100 MB |
| ❌ | Android 16 / Baklava | 别装最新的，容易遇坑 |

#### SDK Tools 标签

| 勾 | 项 | 大小 | 必要性 |
|----|----|------|------|
| ✅ | Android SDK Build-Tools (latest) | ~50 MB | 必装 |
| ✅ | Android SDK Platform-Tools | ~15 MB | 必装（含 adb） |
| ⬜ | Android SDK Command-line Tools (latest) | ~150 MB | 装上更省心（自动接受 license），不装也能用 GUI 出包 |
| ❌ | Android Emulator | ~140 MB | **不要装**（打 APK 不需要模拟器） |
| ❌ | Android Emulator hypervisor driver | - | **不要装** |
| ❌ | Intel x86 Emulator Accelerator | - | **不要装** |

**总下载量 ≈ 300 MB**（不装 cmdline-tools 是 150 MB）

**Apply → 下载**

---

### B1.5 设置环境变量

Windows 设置 → 高级系统设置 → 环境变量：

| 变量名 | 值 |
|--------|---|
| `ANDROID_HOME`（新增用户变量） | `D:\Android\Sdk` |
| `JAVA_HOME`（新增用户变量） | `C:\Program Files\Android\Android Studio\jbr` |

**Path** 追加：
```
%ANDROID_HOME%\platform-tools
%ANDROID_HOME%\cmdline-tools\latest\bin
```

**重启所有命令行窗口**，验证：

```bash
adb --version
# 输出：Android Debug Bridge version 1.0.41 ...
```

能跑就 OK。`'adb' 不是内部或外部命令` → 环境变量没生效，重开终端或重启。

---

### B1.6 SDK 安装成功的验证清单

不依赖 Command-line Tools 的 3 种验证方式：

#### ① Android Studio 里看 Status
SDK Manager 里 **Installed** 列要打勾，不能是 `Not installed` 或感叹号

#### ② 文件夹结构核对
```
D:\Android\Sdk\
├── build-tools\34.0.0\      ← 必须有 aapt2.exe, apksigner.bat
├── platform-tools\          ← 必须有 adb.exe
└── platforms\android-34\    ← 必须有 android.jar
```

#### ③ 命令行
```bash
adb --version
```

3 个里只要 ① + ② 通过，就可以进入打包阶段。

## B6 · 自定义应用图标

> Capacitor 默认用 Android 自带的小绿机器人图标，想换成栖栖 / 迟迟就用这一节。一行命令搞定，不用手动切图。

### B6.1 准备源图

在项目根目录建 `assets/` 文件夹：

```
qichi/
└── assets/
    ├── icon.png            ← 必需，1024×1024 PNG（兼容老安卓 / iOS）
    ├── icon-foreground.png ← 可选，自适应图标前景层（推荐）
    └── icon-background.png ← 可选，自适应图标背景层
```

**栖迟的设计建议**：

| 文件 | 内容建议 |
|------|---------|
| `icon.png` | 橘猫栖栖**居中 + 暖橙圆形背景**，兼容所有老设备 |
| `icon-foreground.png` | 只画橘猫栖栖，**1024 画布中心保留 660×660 安全区**（防止圆切被裁掉头） |
| `icon-background.png` | 纯暖橙色 `#FFA94D` 或暖橙渐变 |

> 自适应图标（Adaptive Icon）是 Android 8.0+ 标准 —— 系统按厂商主题切圆形 / 方形 / 水滴形，所以前景图主体必须居中且留安全边距。

### B6.3 没源图怎么办（3 个生成途径）

#### ① AI 生成（nanobanana / DALL·E）

参考 Prompt：

```
A cute illustrated app icon featuring a round orange tabby cat (橘猫) face,
plump cheeks, big sparkly eyes, gentle smile, sitting upright,
soft warm orange (#FFA94D) gradient background,
flat 2D illustration style, slightly chibi proportions,
1024x1024 pixel, centered composition with 15% safe padding,
no text, soft shadow, healing/cozy aesthetic
```

生成后裁 1024×1024 PNG 即可。

#### ② 在线工具

| 工具 | 特点 |
|------|------|
| **https://icon.kitchen** ⭐ 推荐 | 直接生成 Android 自适应图标三件套 + 实时预览各家手机圆/方/水滴显示效果 |
| https://easyappicon.com | 上传一张 PNG 自动出全套 |
| https://www.appicon.co | 同时出 iOS / Android |

**icon.kitchen 流程**：上传图 → 选背景色 → 下载 zip → 解压后里面就是 `mipmap-*` 文件夹，**直接整体覆盖**到 `android/app/src/main/res/`。

#### ③ 用 app 里现有的角色立绘

直接从 `src/components/.../pet*.png` 拷一张栖栖的高清立绘，加圆形暖橙背景 → 导出 1024 PNG，最契合 app 视觉。

### B6.5 图标设计避坑速查

| 坑 | 解 |
|----|---|
| **主体太靠边** → 老安卓圆切后被裁掉 | 1024 画布中心保留 660×660 安全区 |
| **PNG 带透明但未配 background** | 老启动器显示"穿洞"，要么 icon.png 别透明，要么补 icon-background.png |
| **细节太复杂** | 桌面只 48dp，太细全糊 → 主体要简、要圆、要色块 |
| **拿 SVG 当源** | 分辨率会不对，必须 1024×1024 PNG 当源 |
| **图标更新后手机没变** | 卸载旧 APK 再装新的（启动器图标缓存有时不刷新） |

# 五、常见问题速查

## 网络 / 下载类

| 症状 | 原因 | 解 |
|------|------|------|
| SDK 下载 `Connection closed at byte XXXXX` | Clash 节点不稳 | 换香港节点 + 开 TUN Mode + 只装最小组件集 |
| `Total download size: 0 B`, 全 unavailable | 拉不到 SDK 清单 | 跳过向导，进主界面配 HTTP Proxy 后用 SDK Manager |
| Gradle Sync 卡在 `Downloading https://services.gradle.org/...` | 没走代理 | AS 设置 → HTTP Proxy 配 `127.0.0.1:7890` + Clash 开 TUN |
| 镜像（清华/北外）不通 | 国内镜像基本都停了 | 老老实实用 Clash 走代理 |

## 路径 / 配置类

| 症状 | 解 |
|------|---|
| SDK 红字 `inside Studio's install location` | 改成 `D:\Android\Sdk`（独立路径） |
| 命令行报 `'adb' 不是内部或外部命令` | Path 没加 `%ANDROID_HOME%\platform-tools`，重启终端 |
| Build 报 `SDK location not found` | 手动在 `android/local.properties` 加 `sdk.dir=D\:\\Android\\Sdk` |
| Build 报 `You have not accepted the license agreements` | 装 Command-line Tools 后跑 `sdkmanager --licenses` 全部 y |

## 构建类

| 症状 | 解 |
|------|---|
| `npm run build:apk` 报 `Page changed from static to dynamic` | 排查是不是哪个 page 用了 `cookies()` / `headers()`（v2 应该都没用） |
| `out/` 是空的 | 单独跑 `npm run build:apk` 看 next build 报什么错 |
| APK 装到手机后白屏 | 检查 `next.config.mjs` 的 `BUILD_TARGET=static` 分支是否生效；`out/index.html` 是否存在 |
| APK 装好但翻译报错 | 朋友没填 chatanywhere 的 Base URL，让他进「我 → AI 配置」 |

## 业务类

| 症状 | 解 |
|------|---|
| 朋友说「填了 key 还是说要填 key」 | 检查 IndexedDB → settings 表里 `openaiKey` 字段 |
| Vercel 报 405 method not allowed | 旧的 `/api/*` 路由没删干净，重新 push |
| iOS 朋友找你要 .ipa | 让他用 Safari 打开 Vercel 链接 →「添加到主屏幕」即可 |

# 六、技术架构变化对照（v1 vs v2）

# 七、安全注意

- 用户的 API key 只存在他自己的 IndexedDB，不上传任何服务器
- 使用 OpenAI SDK 的 `dangerouslyAllowBrowser` 模式 —— 名字吓人，但对**本机存储**的 key 是安全的
- **千万别**把任何人的 key 硬编码进代码 / 推到 git
- 提醒朋友：公共电脑用完记得在设置页清空 key
