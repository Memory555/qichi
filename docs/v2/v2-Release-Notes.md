# 栖迟 v2.0 · Release Notes

> 给试用朋友看的"这次更新了什么 + 怎么用"。
> 也是 GitHub Release 描述的主体来源。

---

## 这版的核心改动

栖迟 v2 的主线是**让回看更舒服**：

- 🌙 **暗黑模式** —— 凌晨开屏不再刺眼
- 📅 **面试日程** —— 不只是"事后聊"，也能"提前记"
- 💭 **情绪卡片** —— 心境页不只有曲线了，可以一天一天回看
- ✏️ **复盘可编辑** —— v1 留下来的"即将上线"按钮终于真的上线了
- 🐾 **宠物可改名** —— 不一定要叫栖栖或迟迟

---

## 新增功能

### 1. 暗黑模式 🌙

每个主页右上角都有一个 ☀️ / 🌙 图标，点一下切换浅 / 深。

- 默认浅色
- 选择保留在本机，下次打开沿用
- 多 tab 同步（A tab 切了 B tab 跟随）

### 2. 面试日程 📅

打开「小本本」→ 顶部切换到「日程」tab。

- 月历视图，每天可以**主动添加面试**
- 填公司 / 岗位 / 轮次 / 时间 / 备注（都可不填）
- 面试当天 ☐ 完成 checkbox 一点变 ✓
- 已发生的"复盘"（栖栖 / 迟迟 从聊天里抽出来的）和"日程"（你自己加的）会**同日同卡**显示，但**视觉区分**：
  - 实心 ● = 复盘
  - 圆环 ○ = 日程
- 把外部日历的面试也记到栖迟，就不用切两个 app 了

### 3. 情绪卡片 💭

打开「心境」→ 滚到曲线和月度总结下方。

- 每张卡片代表一天，左边一条 mood 颜色暗示当天主基调
- 卡片只显示**最重要的指示**（日期 / 主导情绪 / 平均分横条 / 当天聊天数 / 当天面了几场）
- **点击卡片** → 抽屉里看完整内容：
  - 当日情绪轨迹（小条形图）
  - 当天面了哪些公司岗位（全部，不限 3 个）
  - 当天你跟宠物说了什么（前 5 条，看更多去小本本）
- 跟着「近 7 天 / 近 30 天 / 全部」联动数量

### 4. 复盘可编辑 ✏️

打开「小本本」→ 任意卡片右上角 ⋯ → 「编辑」。

- 可改：公司 / 岗位 / 轮次 / 被问到的 / 卡住的点 / 答得不错
- 三个列表字段（被问到 / 卡住 / 答得不错）用 textarea **一行一条**，新增 / 删除直接改行
- 保存后这条会标记"我编辑过"，下次再编辑回到上次的内容

### 5. 给宠物起个名字 🐾

打开「我」→ 点头像下方 → 「我和 X」分组 → 「换个名字」。

- 最多 12 字，留空就叫回原名
- 改完之后**聊天里宠物会用新名字称呼自己**（LLM 翻译时也跟着改）

### 6. 一键填 chatanywhere 代理 🔌

打开「我」→ 「AI 配置」展开 → Base URL 输入框下面有一行"一键填 chatanywhere 代理"。

- 不再需要复制粘贴
- 仍然要你自己填 key（这是必须的，栖迟不存任何人的 key）

### 7. 月度总结提示 📬

每个月聊到一定条数（≥ 5 条）后，**聊天页顶部**会出现一条提示：

> 这个月你跟我说了不少。去看看 X 给你写的总结？

点过去会自动生成；点 ✕ 关掉本月不再出现。

## 改动 / 替代

| v1 | v2 |
|----|----|
| 设置页"外观"分组（v2.0 试过三选一） | 每个主页右上角主题图标 |
| 笔记页只能列表流 | 列表 / 日程 二选一 |
| 复盘卡片日期 `M.D` | `YYYY.M.D`（跨年看清楚） |
| 复盘"编辑"按钮 disabled | 全字段可编辑 |
| 聊天页右上角"⚙ 设置入口"图标 | 取消（设置仍可从底部 TabBar "我" 进入） |
| 心境页只有折线图 + 月度总结卡 | + 情绪卡片列表 + 当日详情抽屉 |

---

## 不变的（继承 v1 设计原则）

- **数据只存你本机**，不上云、不上传任何服务器
- **API key 你自己填**（BYOK），仅存本机 IndexedDB
- **没有打卡 / 推送 / 通知**（不打扰原则）
- **栖栖（橘猫）/ 迟迟（柴犬）作为品牌名**保留，可以叠加你自己的昵称

---

## 从 v1 升级

### 网页用户

直接打开 `qichi.vercel.app` 就是 v2 了，**v1 数据完全保留**（IndexedDB 自动加新表）。

### APK 用户

直接**覆盖安装** v2 APK（不要先卸载），**v1 数据完全保留**。

> ⚠️ 如果先卸载再装，IndexedDB 会被系统清掉。**直接覆盖装就好**。

## 接入流程（朋友首次使用，无 v1 数据）

和 v1 完全一样（详见 [v1 部署与分发指南](../v1/部署与分发指南.md) §A3）：

```
打开 qichi.vercel.app
  ↓
选宠物（猫栖栖 / 狗迟迟）
  ↓
聊天页 → 顶部提示「想让 X 跟你说人话？请先在「我」填好 key」
  ↓
点过去 → 填 3 个字段：
  · API Key:   sk-xxxxxx
  · Base URL:  点「一键填 chatanywhere 代理」即可  ← v2 新增
  · 模型留默认就行
  ↓
保存 → 测试连接 → 看到「连通：你好」 → 回聊天页开聊
  ↓
（可选）回设置页改宠物昵称 + 顶部切换浅 / 深主题
```

## 已知边界（v2 不做的）

- 不做面试**提醒** / 推送（保留"不打扰"原则）
- 不做**跨设备同步** / 云端备份（保留"0 后端 + 隐私优先"）
- 不做**情绪打卡**（情绪卡片只展示已聊出来的，不催你写）
- "全部"范围下情绪卡片**最多 60 张**（再多会卡，分页留 v3）
- 暂时无法**从情绪卡片详情直接跳到对应复盘**（文字引导"可以去小本本里翻"）
