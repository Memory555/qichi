## 2. 操作约定（给未来的自己）

### 2.1 占位规则

> "图相同但是名称不同" 占位是**安全的临时方案**：先把代码路径接通，再补真实素材。

操作步骤：
1. 找到目标路径（如 `public/background/dark/欢迎页.png`）
2. 直接 `cp public/background/欢迎页.png public/background/dark/欢迎页.png`（用现有同名图占位）
3. 代码里按目标路径引用
4. 真实素材生好后，**覆盖**占位文件即可（路径不变，无需改代码）

### 2.2 生图工具建议

| 用途 | 推荐 |
|------|------|
| 背景插画（大画幅） | Midjourney v6 + `--ar 9:19`（竖屏） |
| 头像 / 小图标 | Nano Banana（细节控制好，本仓库已有 prompt 示例） |
| Icon SVG | Iconify 或手画 → IconJar 整理 |
| 字体 | OPPO Sans 官方下载（已在本仓库） |

### 2.3 命名约定

- 中文文件名 OK（v1 已有先例：`欢迎页.png`、`聊天页背景.png`）
- 深色版本统一放在子目录 `/dark/` 而非加后缀 `-dark`（路径更清晰）
- icon 用 kebab-case 英文：`monthly-hint-cat.svg`

### 2.4 体积红线

- 单张背景图 ≤ 1.5 MB（v1 欢迎页 1.4 MB 是上限）
- icon SVG ≤ 20 KB
- 字体单档 ≤ 5 MB（OPPO Sans Regular 4.8 MB 已达上限，不可再加）
