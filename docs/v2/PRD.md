## 一、v2 解决的问题

来自 v1 PRD §11「已知局限」+ 首批朋友试用反馈：

1. **深夜场景刺眼** —— 暖橙浅色在凌晨开屏太亮
2. **看不到时间分布** —— 4 个模块只有"按时间倒序的复盘流"，无法直观回答"我这周/这月面了几场"
3. **面试要靠记忆/外部日历安排** —— v1 只能事后聊，没法把"计划面"也放进栖迟
4. **宠物名不可改** —— v1 H2 假设（命名提升粘性）未真正验证
5. **月度总结被动触发** —— 用户不一定每月主动打开曲线页
6. **CORS 配置教育成本高** —— 朋友试用栽在"代理地址怎么填"上的不少
7. **复盘内容无法编辑** —— v1 留下了 "编辑（即将上线）" 入口但功能未做
8. **心境回看维度单一** —— 折线只能看趋势，看不见"那天什么感受 / 在面什么"

## 二、v2 交付的核心能力

> 按 4 模块拆，每条都对应第一节的某个痛点。

### 2.1 全局
- **暗黑模式**：CSS 变量驱动，每个主页 AppBar 右上角图标一键 toggle（对应痛点 1）
- **数据可扩展**：Dexie schema 升级到 v(2)，老用户从 v1 升级 0 迁移；新增 `interviews` 表；`Settings` 加 `customName` 字段

### 2.2 聊天页（首页）
- **月度总结提示 banner**：当月用户消息 ≥ 5 + 未生成总结 + 用户未关闭 → 顶部一行柔暗示，点击跳曲线（对应痛点 5）
- **宠物显示名跟随昵称**：AppBar 头像旁的名字 / 输入框 placeholder / 翻译时 LLM 称呼自己，都走 `getDisplayName()`

### 2.3 笔记页（小本本）
- **列表 / 日程 tab 切换**（v1 只有列表）
- **列表卡片**：
  - 日期 `YYYY.M.D`（v1 只有 `M.D`，跨年看不清）
  - 菜单激活**编辑**功能：BottomSheet 表单可改公司 / 岗位 / 轮次 / 被问到的 / 卡住的点 / 答得不错（对应痛点 7）
- **日程视图**（取代 v1 没有的日历）（对应痛点 2、3）：
  - 月历网格，按月翻页
  - 每日格子双层指示：上排 brand 实心点（review，聊天里 AI 抽取的）+ 下排 brand 圆环（interview，用户手动添加的日程）
  - 点格子 → 抽屉：日程列表（带完成 checkbox / 编辑 / 删除）+ 复盘列表 + 顶部 "+ 添加面试" 按钮

### 2.4 心境页（曲线）
- 折线图 + range 切换（v1 已有，保留）
- **情绪卡片列表（新）**（对应痛点 8）：
  - 卡片极简：日期 + 主导情绪 chip + mood 横条 + "N 场 · N 条" 指示
  - 卡片左侧 4px mood-tone 边框暗示情绪基调
  - 点击 → BottomSheet 抽屉：情绪轨迹小条形图 / 当日全部事件 / 前 5 条聊天
  - limit 跟随 range：7→7、30→30、全部→60
- 月度总结卡（v1 已有，保留）

### 2.5 设置页（我）
- **顶部主题切换图标**（与其他主页一致）
- **换个名字**：BottomSheet 输入框，留空叫回品牌名，最多 12 字（对应痛点 4）
- **LLM 配置加一键填 chatanywhere 代理按钮**（对应痛点 6）

## 四、明确**不做**的（v2 边界 · 防 scope creep）

继承 v1 PRD §5.3 + v2 新增排除：

- ❌ 跨设备同步 / 云端备份（破坏"0 后端、隐私优先"原则）
- ❌ 流式翻译（增益不够大，单独立项）
- ❌ 宠物互动手势（喂食 / 拍头，素材成本高）
- ❌ 更多宠物种类（v1 已排除，延续）
- ❌ 树洞 / 社交 / 评论
- ❌ 自建 LLM 中转后端（保留 BYOK）
- ❌ 主动推送通知（保留"不打扰"原则）
- ❌ 面试日程的提醒 / 闹钟（v2.1 决策，保留"不打扰"）
- ❌ 情绪打卡 / 强制写日记（v2.1 决策，保留"安全感优先"）
- ❌ 情绪卡片详情里跳转到 review 详情页（v2.3 决策，避免 BottomSheet 嵌套）
- ❌ 全部模式情绪卡片不分页（v2.2 决策，60 张封顶；分页留 v3）
- ❌ 多设备数据合并 / 冲突解决

## 五、验收标准（GA 准入线）

> 完整可执行 checklist 见 [`验收清单.md`](./验收清单.md)。本节只列 GA 准入条件。
